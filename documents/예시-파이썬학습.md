# 파이썬 딕셔너리 정리

오늘은 파이썬 딕셔너리(dict)를 공부했다. 키-값 쌍으로 데이터를 저장하는
자료구조다.

## 기본 사용법
```python
d = {"이름": "철수", "나이": 20}
print(d["이름"])      # 철수
d["취미"] = "등산"     # 추가
```

## 자주 쓰는 메서드
- `d.get(key, 기본값)` : 키가 없어도 에러 없이 기본값 반환
- `d.keys()`, `d.values()`, `d.items()` : 순회할 때 사용
- `for k, v in d.items():` 패턴이 가장 많이 쓰인다
