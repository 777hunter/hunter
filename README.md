# 무음카메라 (Silent Camera)

셔터음 없이 사진을 촬영하는 웹 카메라입니다. 앱 설치 없이 브라우저에서 바로 사용할 수 있습니다.

## 왜 무음인가요?

휴대폰 기본 카메라 앱의 셔터음은 OS(또는 법적 규제)에서 재생하는 소리입니다.
이 앱은 브라우저의 카메라 화면을 `canvas`로 그대로 복사해 이미지를 만들기 때문에
**셔터음이 전혀 발생하지 않습니다.** 도서관, 회의, 아기가 자는 방 등에서 유용합니다.

## 사용 방법

1. `index.html` 파일을 휴대폰이나 PC의 브라우저로 엽니다.
   - 카메라 권한은 **HTTPS** 또는 **localhost**에서만 허용됩니다.
   - GitHub Pages로 배포하면 바로 `https://<사용자>.github.io/hunter/` 로 접속해 쓸 수 있습니다.
2. **카메라 시작** 버튼을 누르고 권한을 허용합니다.
3. 가운데 흰색 **셔터 버튼**을 누르면 소리 없이 촬영됩니다.
4. 왼쪽 아래 **미리보기**나 오른쪽 위 **▦ 갤러리** 아이콘으로 촬영한 사진을 보고 저장(⤓)합니다.

## 기능

- 🔇 **완전 무음** 촬영 (오디오 트랙 미사용)
- 🔄 **전/후면 카메라 전환**
- ⏱ **타이머** (끔 / 3초 / 5초 / 10초)
- ▦ **격자선** 표시 (구도 잡기)
- 🖼 **갤러리**에서 촬영본 확인 및 다운로드
- 📱 모바일 전체화면 UI

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages** 로 이동합니다.
2. **Source** 를 배포할 브랜치로 지정하고 저장합니다.
3. 몇 분 뒤 안내된 주소로 접속하면 폰에서 바로 무음카메라를 쓸 수 있습니다.

## 참고

- 촬영한 사진은 서버로 전송되지 않고 **브라우저 안에서만** 처리됩니다.
- 페이지를 새로고침하면 저장하지 않은 사진은 사라지니 필요한 사진은 ⤓ 로 내려받으세요.
