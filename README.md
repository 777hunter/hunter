# 무음카메라 (Silent Camera) 📷🔇

셔터음 없이 사진을 촬영하는 **설치형 웹 카메라(PWA)** 입니다.
폰 홈 화면에 설치하면 일반 앱처럼 아이콘이 생기고 전체화면으로 실행됩니다.
앱스토어 등록·APK 설치 없이 사용할 수 있습니다.

## 왜 무음인가요?

휴대폰 기본 카메라 앱의 셔터음은 OS(또는 법적 규제)에서 재생하는 소리입니다.
이 앱은 카메라 화면을 `canvas`로 그대로 복사해 이미지를 만들기 때문에
**셔터음이 전혀 발생하지 않습니다.** 도서관, 회의, 아기가 자는 방 등에서 유용합니다.

## 설치 방법 (설치형 앱으로 쓰기)

> ⚠️ 카메라와 설치 기능은 **HTTPS 주소**에서만 동작합니다. GitHub Pages 배포 주소로 접속하세요.

### 1) 배포 (최초 1회)
- 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정합니다.
- `main` 브랜치에 병합되면 `.github/workflows/deploy.yml` 이 자동으로 배포합니다.
- 배포 주소: `https://777hunter.github.io/hunter/`

### 2) 폰에 설치
- **안드로이드 (크롬)**: 접속 후 상단의 **⤓ 설치** 버튼을 누르거나, 메뉴 → **앱 설치 / 홈 화면에 추가**.
- **아이폰 (사파리)**: 하단 **공유 버튼(￪)** → **홈 화면에 추가**.
- 설치 후에는 홈 화면 아이콘으로 실행하면 주소창 없이 전체화면 앱처럼 열립니다.

## 사용 방법

1. 앱을 열고 **카메라 시작** 버튼을 눌러 권한을 허용합니다.
2. 가운데 흰색 **셔터 버튼**을 누르면 소리 없이 촬영됩니다.
3. 왼쪽 아래 **미리보기** 또는 오른쪽 위 **▦ 갤러리**로 사진을 보고 저장(⤓)합니다.

## 기능

- 🔇 **완전 무음** 촬영 (오디오 트랙 미사용)
- 📲 **설치형(PWA)** — 홈 화면 설치, 전체화면 실행, 오프라인 실행
- 🔄 **전/후면 카메라 전환**
- ⏱ **타이머** (끔 / 3초 / 5초 / 10초)
- ▦ **격자선** 표시 (구도 잡기)
- 🖼 **갤러리**에서 촬영본 확인 및 다운로드

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 본체 (UI + 카메라 로직) |
| `manifest.json` | PWA 설정 (앱 이름·아이콘·전체화면) |
| `sw.js` | 서비스워커 (오프라인 캐시·설치 지원) |
| `icon-*.png` | 앱 아이콘 |
| `.github/workflows/deploy.yml` | GitHub Pages 자동 배포 |

## 참고

- 촬영한 사진은 서버로 전송되지 않고 **브라우저(기기) 안에서만** 처리됩니다.
- 페이지를 새로고침하면 저장하지 않은 사진은 사라지니 필요한 사진은 ⤓ 로 내려받으세요.
