# 브레이징 공정 셀라인 설계 및 작업 환경 개선 논의 (개조식)

**2026-09-29**

---

## 1. 공정 자동화 개선

### 1.1 프론트 인쇄 공정
- 자동 도공기: 롤러 좌우 슬립(약 2mm) 발생 → 미세 튜닝 중
- 기타 공정: 완료

### 1.2 EM 표준 트레이
- 현황: 페트리디시 보관 → 측정 시 현미경 계속 조정 필요
- 개선: 표준 트레이로 보관-측정-IV 투입까지 선형성 확보
- 진행: 프로토 샘플 1개 제작 후 유효성 확인 예정

### 1.3 에이징 헬륨 가압 챔버
- 개조 견적: 1,000만원 → 마지노선 500~600만원
- 검토: 리크 테스트 목적이면 헬륨 필수 아님 (질소/아르곤 무방)
- 연간 비용: 헬륨 본 1개 약 50만원(2개월 사용)
- 재보고 필요

### 1.4 브레이징 셀라인 (통합 작업대)
**설계안:**
- 1번: 부품 지그 → 2번: 방수 지그 → 3번: 안착지그(탈가스/시저파) → 4번: 안착지그(에이징/시저파) → 5번: 조립정렬 → 6번: 세라믹 안착
- 표준 수량(30~40개) 완료 후 브레이징 장비에 투입(역순 회수)
- 목표: 신입도 작업 편성 설명만으로 가능

**설계 조건:**
- 중량: 11kg → 6kg으로 감량
- 레벨풋 고정 + 이동 시만 캐스터
- 공간: 1,500~1,600mm 고려 (통로/메인터넌스 포함)

**지적된 리스크:**
- 지그 간 충돌/스크래치
- 적층으로 인한 작업대 그늘(조명 보강 가능)
- 상단 지그 낙하 시 하부 작업물 흐트러짐
- 진공 브레이징 열전달(복사) 영향 검토 필요
- 인간공학적 높이 적정성

**진행방식:**
- 3번 지그 제작 평가 → 이상 없으면 4번 평가 → 전체 구현
- 지그 재질 열 평가 선행 후 컨셉/디자인 병행

**일정:** 11월 말 셋업 목표

## 2. 생산 캐파

### 2.1 튜브 캐파
- 480개: 인원 추가/지그 부족 상태로 진행 → 보완 필요
- 560개: 투자 금액, 투자 시점 정리 후 재보고

### 2.2 FE 제너레이터(목표 90대)
- 진행: TM 공정 85대 검증 완료 → 이후 공정 순차 검증 지연
- 원인: 제조 인력/생산계획 부재
- 개선안: 공정별 시간당 생산량 측정 → 90대 도달 가능성 1차 확인 → 라인 밸런스
- 협의 필요: 제조 + 본부장

### 2.3 10월 물량 & W 증산
- 10월: 약 890대(1,000대 미달)
- W 1,000대 증산 요청: 병목은 에이징 → 3개월 분산 + 헤드 선행 생산으로 대응
- 모델 미확정 상태이므로 헤드만 선행 재고

### 2.4 외주화
- **결정:** 진행 안 함 → 작업 표준화로 마무리
- 불가 사유 정리 후 과제 종결

## 3. 품질 & 직행률

### 3.1 튜브 직행률
- 투입: 기성주 지그, 보강, 베이킹 4종
- 결과: 눈에 띄는 개선 효과 없음 (5-1 채널 불량률 20% 이상)
- 원인: 세라믹/브레이징 로트 영향 의심
- 조치: Minitab 2-sample t-test로 유효성 검증 → 효과 없는 항목 정리

### 3.2 로트 추적성 이슈
- 전극 로트(0701): 포장일자 ≠ 실제 가공일자
- 세라믹 로트: 표기 혼입/분산 가능성
- 실제 가공 시점 확인 필요

### 3.3 EM 백화 현상
- 테두리 백화 발생 → CNT 개발팀 공동 분석
- 원인 규명 전까지 라인 미투입

### 3.4 게이트 시트 세정
- **방향 전환:** 양산 적용 → 선행 공정 개발 목적
- 이유: Min-Max 검사 기준 수립 어려움, 사람 편차 제거 불가
- 안정화 후 공정 적용

### 3.5 기타 불량
- **스크래치:** 주 1회 실리콘 지그 물 세척, 작업 전 육안 확인
- **몰딩 깨짐:** 보관 온도 낮춤 → 1개월 이상 미발생
- **트랜스 불량(에어 투월):** 제작 공정 불량으로 추정, 사전 검출 곤란 → 가이드 강화/파괴 분석
- **튜빙 위치 이탈:** 업체 실수 아닌 표준 유무 및 준수 여부부터 확인

### 3.6 203 불량(캐패시터)
- 증상: 내부 파열, K/M Ω 레벨 모두 발생
- 특징: GOG108 모델 집중, 동일 로트 특정 캐패시터에서만
- 로트: 경신반도체 5,000~6,000개 단위 (산발적)
- 베이킹 이행 기록 미흡 → 관리 체계 점검

## 7. W 튜브 신뢰성 & 교체

### 7.1 현황
- 가동 후 언제 죽느냐가 문제 (100포 vs 실제 400~1,000회)
- 70KV/5mm Al 영역대까지 미도달

- 트랜스 + 제너레이터 조합 문제 가능성

### 7.2 교체 방안
- 기설치 물량: 약 1,000대
- 개선품: 약 200대
- 판매 희석 불가 → **전량 교체 결정**
- 예상 규모: 1,000~2,000대
- 타이밍: 11~12월(물량 감소 시기) 적절
- 준비: 10월 후반부터 착수
