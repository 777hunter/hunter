# 대시보드 유형 예시

대표적인 대시보드 4가지 유형 + 이 저장소의 날씨 데이터를 적용한 예시 1개.
각 HTML을 브라우저로 열면 그대로 보이고, `screenshots/`에 캡쳐 이미지가 있습니다.

| 파일 | 유형 | 사용자 | 답하는 질문 | 갱신 주기 |
|---|---|---|---|---|
| `01-strategic.html` | **전략 (Strategic)** | 경영진 | 목표 대비 어디까지 왔는가 | 월 1회 |
| `02-analytical.html` | **분석 (Analytical)** | 분석가·기획자 | 왜 이렇게 되었는가 | 일 1회 |
| `03-operational.html` | **운영 (Operational)** | 운영·관제팀 | 지금 이상이 있는가 | 10초 |
| `04-tactical.html` | **전술 (Tactical)** | 팀장·PM | 계획대로 가고 있는가 | 주 1회 |
| `05-weather.html` | **정보성 (Informational)** | 누구나 | 오늘 상황이 어떤가 | 발표 시각 |

## 유형별 특징

- **전략** — 소수의 KPI를 큰 숫자로. 히어로 숫자 1개, 목표 대비 달성률, 추세는 스파크라인 정도로 압축.
- **분석** — 시계열·코호트·세그먼트 비교가 중심. 기간 필터와 표 보기로 드릴다운.
- **운영** — 임계치와 상태(정상/주의/경고/위험)가 주인공. 알람 큐가 붙고 색만이 아니라 아이콘·라벨로 상태를 표시.
- **전술** — 계획 대비 실적, 마일스톤, 담당자별 부하 등 실행 관리용 지표.
- **정보성** — 판단보다 전달이 목적. 이 저장소 `weather/2026-08-05.md` 데이터를 그대로 사용.

## 구성

```
dashboards/
├── assets/dashboard.css   공통 토큰·레이아웃
├── assets/charts.js       외부 의존성 없는 SVG 차트 (막대/누적/선/가로막대/히트맵/범위막대/스파크라인)
├── capture.js             Playwright로 전체 화면 캡쳐
└── screenshots/*.png      캡쳐 결과 (2x)
```

캡쳐 재생성:

```bash
node dashboards/capture.js
```

## 차트 규칙

- 카테고리 색은 고정 순서로 배정(파랑 → 주황 → 청록 …), 순위에 따라 바뀌지 않음.
- 이중 y축 없음. 막대 두께 24px 이하, 데이터 끝 4px 라운드, 선 2px.
- 시리즈 2개 이상이면 범례 필수, 값 라벨은 끝점·최댓값 등 선별적으로만.
- 상태 색은 아이콘 + 라벨과 함께 사용(색만으로 의미를 전달하지 않음).
- 색상 대비·색각 이상 분리도는 검증 스크립트로 확인한 팔레트를 사용.

모든 수치는 예시용 샘플 데이터입니다(날씨 대시보드 제외).
