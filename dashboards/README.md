# 대시보드 총괄 (Dashboard Hub)

지금까지 만든 대시보드가 흩어져 있어서, **주소 + 무엇을 하기 위한 것인지**를 한 곳에 모아
관리하는 색인 페이지입니다.

- 허브 주소: <https://claude.ai/code/artifact/1cf47edb-9904-4208-a8bf-a7e1e525cd6d>
- 현재 등록: 10건

## 파일

| 파일 | 역할 |
| --- | --- |
| `hub.html` | 허브 페이지 원본. 레지스트리가 `<script id="state">` 블록 안에 JSON으로 들어 있습니다. |
| `registry.json` | 레지스트리 사본(사람이 읽기 쉬운 형태). 동기화할 때 같이 갱신합니다. |
| `sync.py` | Artifact 목록과 대조해 새 대시보드를 자동 편입하는 스크립트. |

## 화면에서 할 수 있는 것

- **검색 / 분류 필터 / 정렬** — 제목·용도·태그로 찾고, 공정·분석 / 학습·자료 / 보고서 /
  안전·환경 / 시스템·도구 / 미분류로 걸러 봅니다.
- **관리자 모드** (편집 권한이 있는 계정에서만 버튼이 보입니다)
  - `숨김` — 목록에서 내립니다. 관리자 모드에서 "숨긴 항목도 보기"를 켜면 다시 나옵니다.
  - `고정` — 항상 맨 위로 올립니다.
  - `편집` — 제목·용도·분류·태그·아이콘·주소를 고칩니다.
  - `목록에서 제거` — 레지스트리에서 빼고 `tombstones`에 남겨, 다음 동기화 때 다시
    들어오지 않게 합니다. (대시보드 자체는 지워지지 않습니다.)
  - `＋ 대시보드 추가` — 주소를 붙여 넣어 직접 등록합니다.
  - 바꾼 내용은 **저장**을 눌러야 반영됩니다. 저장하면 페이지가 자기 자신을 새 버전으로
    발행하고, 열려 있는 모든 화면이 새 버전으로 다시 불러옵니다.

> 숨김은 **정리용**이지 보안 기능이 아닙니다. 숨긴 항목도 페이지 소스의 레지스트리에는
> 남아 있고, 원래 대시보드 주소를 아는 사람은 그대로 열 수 있습니다.

## 새 대시보드 자동 편입

새 대시보드를 만들면 아래 동기화가 돌 때 `신규 편입` 표시와 함께 `미분류`로 자동으로
들어옵니다. 관리자 모드에서 용도 한 줄과 분류만 채우면 끝입니다.
사람이 손댄 값(용도·분류·숨김·고정·태그)은 동기화가 절대 덮어쓰지 않고,
최종 수정일과 (직접 고치지 않은) 제목만 갱신합니다.

### 동기화 절차

Claude 세션에서 이 순서로 실행합니다. (정기 실행으로 걸어 두면 자동으로 돌아갑니다.)

1. `Artifact` 도구의 `action: "list"` 로 보유한 아티팩트 목록을 받습니다.
2. 목록을 `artifacts.json` 으로 저장합니다 — 항목마다
   `{"id", "title", "url", "icon", "updated"}`.
3. `Artifact` 도구의 `action: "read"` 로 허브(위 주소)의 현재 발행본을 내려받습니다.
4. 병합합니다:

   ```bash
   python3 dashboards/sync.py \
     --html <내려받은 발행본.html> \
     --list artifacts.json \
     --out dashboards/hub.html \
     --registry dashboards/registry.json
   ```

5. 변경이 있으면 `Artifact` 도구로 `url` 을 지정해 `dashboards/hub.html` 을 다시 발행하고,
   저장소에도 커밋합니다. 변경이 없으면 아무것도 하지 않습니다.

`--dry-run` 을 붙이면 무엇이 바뀌는지만 확인할 수 있습니다.

### 정기 실행

주 1회(매주 월요일 09:00 KST) 자동으로 도는 Routine이 걸려 있습니다.
`대시보드 총괄 허브 주간 동기화` — 변경이 없으면 아무것도 하지 않고, 새 대시보드가 있을
때만 허브를 다시 발행하고 커밋합니다. 주기를 바꾸거나 끄려면 claude.ai의 Routines에서
수정하면 됩니다.

## 즐겨찾기에 있는 대시보드 가져오기

사내 시스템(VTS/VKS 등)이나 일반 대화에서 만든 대시보드는 Claude 아티팩트 갤러리에
잡히지 않아 주간 동기화로는 들어오지 않습니다. 브라우저 즐겨찾기를 통째로 가져오면 됩니다.

1. 크롬/엣지/웨일에서 **즐겨찾기 관리 → ⋮ → 즐겨찾기 내보내기** 로 HTML 파일을 저장합니다.
2. 어떤 폴더가 있는지 봅니다.

   ```bash
   python3 dashboards/import_bookmarks.py --html dashboards/hub.html \
     --bookmarks bookmarks.html --list-folders
   ```

3. 가져올 폴더만 골라 미리 확인하고(`--dry-run`), 실제로 넣습니다.

   ```bash
   python3 dashboards/import_bookmarks.py --html dashboards/hub.html \
     --bookmarks bookmarks.html --folder "VTS 자동대시보드" \
     --out dashboards/hub.html --registry dashboards/registry.json
   ```

4. 허브를 다시 발행하고 커밋합니다.

이미 등록된 항목은 주소(아티팩트면 아티팩트 id)로 알아보고 건너뜁니다. `--folder` 를 빼면
파일 안의 모든 즐겨찾기를 가져오므로, 대시보드가 아닌 링크까지 섞이지 않게 폴더를 지정하는
편이 좋습니다. 즐겨찾기 폴더 이름은 태그로 남으니 나중에 분류하기 쉽습니다.

가져온 항목 중 claude 아티팩트가 아닌 것은 `bm-` 로 시작하는 id를 받아, 주간 동기화가
건드리지 않고 그대로 유지됩니다.
